# WP-003 UI 基线

> 状态：CURRENT / 当前工作区  
> 日期：2026-09-01  
> 范围：书架、阅读器、陪读工作区、全书提取、知识晶体的现有能力重排；不新增数据模型或产品能力。

## 设计目标

读见 v1 的界面以“内容优先、空间稳定、状态诚实、操作克制”为基线。视觉语言使用本机系统字体、低饱和暖灰与研究型排版，不依赖外部字体、UI 框架或云端资源。

## 页面层级

- 书架：继续阅读是主任务；导入和本地保存边界在首屏可见。
- 阅读器：正文占据主要空间；目录、进度、主题与返回书架保持固定位置。
- 陪读工作区：动作区、对话区、输入区稳定分层；单次请求只保留一个连续状态气泡。
- 全书提取（Experimental）：按“解析 → 分块提取 → 综合框架 → 完成”叙述，分块进度只使用真实的已完成数量，不模拟剩余时间。
- 知识晶体：每条内容按“来源 → 正文 → 回到原书 / 复制 / 删除”组织；长内容可展开与收起。

## 状态约定

- 进行中：暖色状态点与克制的透明度动画；不使用循环增长的虚假进度。
- 成功：绿色状态与明确的后续动作。
- 失败：红色容器、可理解原因与重试入口；已完成的提取分块保留在本地。
- 来源跳转：继续标注为“实验性”，不暗示所有 EPUB 均能精确定位。

## 技术边界

浅色与深色共享 CSS 变量；EPUB iframe 由 epub.js 主题注入匹配背景与正文颜色。Markdown 仍只通过 `skills/markdown.js` 安全渲染。书卡的“开始阅读 / 继续阅读”只读取既有 `progress:<书名>` 键，不写入新状态。
