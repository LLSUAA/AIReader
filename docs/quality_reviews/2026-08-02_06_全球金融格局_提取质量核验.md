## 三、发现的问题

### P1（影响骨架可用性）

1. **章节标题大量为 AI 自拟**：骨架中"《全球金融网络与美元中心地位》""《传染的机制：网络传播与资本流传染》""《金融制裁的武器化机制与层级》"等标题在原文中不存在（原文为"第1章 一张网，而非一堆国"等）；第一篇、第三篇的篇名也被改名（原文为"网络的形状""制裁与武器化"）。根因：Map 阶段只拿到"第 N 节"的序号标签，模型不知道真实章节名，只能自拟。
2. **第 3 章（连接靠什么维系：支付、清算与跨境信贷）整章缺失**：代理行网络、清算系统拓扑、网络"开关"是后续制裁篇的逻辑基础，骨架不应漏掉。

### P2（细节失真）

3. "全球支付网四层开关"应为"三层开关（清算、通信、合规）"——全文唯一明确的数字改写错误。
4. "资本流传染最快最致命"属于第 6 章，被写进了第 7 章条目（内容不错、归属错位）。
5. Mermaid 概念图中"多极碎片"节点出现两次（V 与 Z），应合并为一个节点。
6. 第零篇管道清单漏了央行互换额度层；日本金融体系特殊性被简化。

## 四、归因与已实施的修复

**为什么准确性高**：Map 阶段"只基于给定文本、禁止训练记忆补充"的约束 + 结构化 schema + 逐块提取，基本压制了幻觉——这是管线设计生效的直接证据。

**为什么标题漂移**：切分器只给块标了"第 N 节"，模型没有原文标题可引用，只能自拟合并。已修复：

- `buildBookChunks()` 现在从每个 spine 文档提取**首个标题元素**作为块标签（真实章节名）；
- Map prompt 要求标题"原样使用文本中的章节标题"；
- Reduce prompt 新增硬约束：标题必须使用原文章节名、禁止自拟/合并/改名；所有章节必须覆盖；数字必须与摘要一致；Mermaid 节点禁止重复。
