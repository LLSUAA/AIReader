# 提取质量核验

全书提取的“能运行”与“值得信任”是两件事。本目录保存真实书籍的人工抽检结果，用来决定是否需要改 Prompt、改切块、加校准入口或调整产品承诺。

## 核验要求

每本书至少记录：

1. 书名、来源格式、题材、字数/分块数、模型和提取耗时；
2. 论断准确性：是否能在原文找到依据；
3. 结构忠实度：章节是否遗漏、合并、改名或顺序错乱；
4. 概念质量：定义是否准确，是否出现模型自带知识；
5. 来源标注：`【C编号】` 是否指向合理分块；
6. 失败与降级：超时、JSON 修复、空内容、失败块和断点恢复；
7. 内容转化：是否能据此完成文章或 10 分钟以内的视频初稿；
8. 明确结论：继续开发、调整使用说明，或暂不处理。

## 建议评分

使用 1-5 分，并写一句证据，不只给主观分数：

- 5：几乎无需修正；
- 4：有少量措辞或遗漏问题，不影响使用；
- 3：可作草稿，必须对照原文；
- 2：结构或事实问题明显；
- 1：不能作为可靠框架使用。

单本书的高分不能外推到全部题材。至少完成 5 种类型样本后，再讨论是否进入人工校准开发。
